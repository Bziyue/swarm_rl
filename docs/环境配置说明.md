## 三、两种基类说明

### 1. DirectRLEnv - 单智能体强化学习环境

```python
from isaaclab.envs import DirectRLEnv, DirectRLEnvCfg

@configclass
class QuadcopterVelEnvCfg(DirectRLEnvCfg):
    # 配置类：定义场景、奖励、观测等参数
    ...

class QuadcopterVelEnv(DirectRLEnv):
    # 环境类：实现单无人机速度控制
    ...
```

**特点：**
- 使用 `gymnasium` 单智能体接口
- `action` 和 `observation` 是 `torch.Tensor`
- 适用于单个无人机的控制任务

### 2. DirectMARLEnv - 多智能体强化学习环境

```python
from isaaclab.envs import DirectMARLEnv, DirectMARLEnvCfg

@configclass
class SwarmAccEnvCfg(DirectMARLEnvCfg):
    # 配置类
    ...

class SwarmAccEnv(DirectMARLEnv):
    # 环境类：实现多无人机蜂群控制
    ...
```

**特点：**
- 使用 `PettingZoo` 多智能体接口
- `action` 和 `observation` 是 `dict[str, torch.Tensor]`
- 每个无人机是一个独立的智能体（如 `drone_0`, `drone_1`...）
- 支持多智能体之间的协作与避碰

## 五、核心方法实现

每个环境都需要实现以下关键方法：

```python
class SomeEnv(DirectRLEnv or DirectMARLEnv):
    
    def _setup_scene(self):
        """设置场景：创建无人机、地形、灯光等"""
        # 为每个智能体创建无人机
        for i, agent in enumerate(self.cfg.possible_agents):
            drone = Articulation(
                self.cfg.drone_cfg.replace(
                    prim_path=f"/World/envs/env_.*/Robot_{i}",
                )
            )
            self.scene.articulations[agent] = drone
        
        # 克隆环境实现并行
        self.scene.clone_environments(copy_from_source=False)
        
    def _pre_physics_step(self, actions):
        """物理步进前：处理动作（反归一化、坐标变换等）"""
        # actions: dict[str, torch.Tensor] for MARL
        # actions: torch.Tensor for single agent
        
    def _apply_action(self):
        """应用动作：将控制指令发送给仿真器"""
        
    def _get_observations(self):
        """获取观测：返回状态向量"""
        # 返回 shape: [num_envs, obs_dim]
        
    def _get_rewards(self):
        """计算奖励：返回奖励值"""
        # 返回 shape: [num_envs]
        
    def _get_dones(self):
        """判断终止：返回是否结束episode"""
        
    def _reset_idx(self, env_ids):
        """重置环境：重置指定环境的状态"""
```

## 六、并行机制实现

### 核心思想：向量化（Vectorized）

IsaacLab 使用 **GPU 并行仿真**，不是 Python 多进程！所有环境在 GPU 上同时运行：

```
传统多进程:  创建 1000 个 Python 进程 → 每个运行一个环境 → CPU/GPU 来回切换 → 慢

IsaacLab:   1 个 Python 进程 → GPU 上并行仿真 10000 个环境 → 全部在 GPU 上计算 → 快
```

### 配置并行数量

```python
@configclass
class SwarmAccEnvCfg(DirectMARLEnvCfg):
    # 场景配置：默认10000个并行环境
    scene: InteractiveSceneCfg = InteractiveSceneCfg(
        num_envs=10000,           # 并行环境数量
        env_spacing=15,           # 环境间距（米）
        replicate_physics=True    # 启用物理复制优化
    )
```

### 数据使用 Batch 维度

所有数据都是 `[num_envs, ...]` 形状的 Tensor：

```python
def _pre_physics_step(self, actions: dict[str, torch.Tensor]):
    # actions: {"drone_0": [num_envs, 2], "drone_1": [num_envs, 2], ...}
    
    for agent in self.possible_agents:
        # 同时处理所有环境的动作
        a_xy_desired = actions[agent] * self.cfg.a_max[agent]  # [num_envs, 2]
        
        # 同时更新所有环境的期望速度
        self.v_desired[agent][:, :2] += self.a_desired[agent][:, :2] * self.physics_dt

def _get_observations(self) -> dict:
    # 同时读取所有环境的观测
    obs = {
        agent: torch.zeros(self.num_envs, obs_dim, device=self.device)
        for agent in self.possible_agents
    }
    return obs
```

## 七、控制模式对比

| 环境 | 动作空间 | 控制指令 | 适用场景 |
|-----|---------|---------|---------|
| `bodyrate` | 3D | 期望角速度 | 底层姿态控制 |
| `vel` | 3D | 期望速度 | 中层速度控制 |
| `acc` | 2D/3D | 期望加速度 | 中层加速度控制 |
| `waypoint` | 3D | 目标位置 | 高层路径规划 |
| `aj` | 混合 | 角速度+加速度 | 复合控制 |

## 八、蜂群任务类型

蜂群环境支持多种任务模式：

```python
mission_names = ["migration", "crossover", "crossover_v1", "chaotic", "cluster_swap"]
mission_prob = [0.0, 0.25, 0.05, 0.0, 0.7]
```

| 任务 | 说明 |
|-----|------|
| `migration` | 迁徙任务：所有无人机飞向同一目标 |
| `crossover` | 交叉穿越：无人机互相穿越 |
| `crossover_v1` | 变体交叉任务 |
| `chaotic` | 混沌任务：随机运动 |
| `cluster_swap` | 集群交换：多组无人机交换位置 |
