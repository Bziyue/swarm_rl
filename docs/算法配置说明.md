# 算法配置说明

## 一、支持的 RL 库

本项目支持三个开源 RL 库：

| RL 库 | 路径 | 算法支持 | 适用场景 |
|-------|------|---------|---------|
| **skrl** | `reinforcement_learning/lib/skrl/` | PPO, IPPO, MAPPO, A2C, DDPG, DQN, SAC, TD3, TRPO等 | 支持多智能体和 IsaacLab |
| **rsl_rl** | `reinforcement_learning/lib/rsl_rl/` | PPO | ETH Zurich leggedrobotics 组开发，高性能 |
| **stable-baselines3** | `reinforcement_learning/lib/stable-baselines3/` | PPO, A2C, SAC, TD3, DDPG, DQN等 | 最常用的开源 RL 库 |

## 二、配置架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        配置分层结构                                       │
├─────────────────────────────────────────────────────────────────────────┤
│  第1层: 环境注册表 (gym.register)                                        │
│         └── 在 envs/xxx_env.py 底部注册环境和配置入口                     │
├─────────────────────────────────────────────────────────────────────────┤
│  第2层: 算法配置文件 (config/agents/)                                    │
│         ├── YAML 格式: skrl, sb3                                        │
│         └── Python 类: rsl_rl                                           │
├─────────────────────────────────────────────────────────────────────────┤
│  第3层: Hydra 命令行覆盖                                                 │
│         └── 通过命令行参数动态修改配置                                    │
└─────────────────────────────────────────────────────────────────────────┘
```

## 三、配置入口点 (Entry Points)

每个环境在注册时定义了多个配置入口点：

```python
gym.register(
    id="FAST-Swarm-Acc",
    entry_point=SwarmAccEnv,
    kwargs={
        "env_cfg_entry_point": SwarmAccEnvCfg,                    # 环境配置
        "sb3_cfg_entry_point": f"{agents.__name__}:swarm_sb3_ppo_cfg.yaml",
        "skrl_ppo_cfg_entry_point": f"{agents.__name__}:swarm_skrl_ppo_cfg.yaml",
        "skrl_ippo_cfg_entry_point": f"{agents.__name__}:swarm_skrl_ippo_cfg.yaml",
        "skrl_mappo_cfg_entry_point": f"{agents.__name__}:swarm_skrl_mappo_cfg.yaml",
        "rsl_rl_cfg_entry_point": f"{agents.__name__}.swarm_rsl_rl_ppo_cfg:SwarmAccPPORunnerCfg",
    },
)
```

| 入口点 | 用途 | 格式 |
|--------|------|------|
| `env_cfg_entry_point` | 环境参数 | Python 类 |
| `sb3_cfg_entry_point` | Stable Baselines3 配置 | YAML |
| `skrl_ppo_cfg_entry_point` | skrl PPO 配置 | YAML |
| `skrl_ippo_cfg_entry_point` | skrl IPPO (多智能体) | YAML |
| `skrl_mappo_cfg_entry_point` | skrl MAPPO (多智能体) | YAML |
| `rsl_rl_cfg_entry_point` | RSL-RL 配置 | Python 类 |

## 四、配置文件详解

### 1. skrl 配置 (YAML)

文件：`config/agents/swarm_skrl_ppo_cfg.yaml`

```yaml
seed: 42

# 神经网络模型配置
models:
  separate: True  # 策略和价值网络分离
  policy:
    class: GaussianMixin           # 连续动作高斯策略
    clip_actions: False
    clip_log_std: True
    min_log_std: -20.0
    max_log_std: 2.0
    initial_log_std: 0.0
    network:
      - name: net
        input: STATES
        layers: [1024, 1024, 1024, 512, 512, 256]  # 网络结构
        activations: elu
    output: ACTIONS
  
  value:
    class: DeterministicMixin      # 确定性价值函数
    network:
      layers: [1024, 1024, 1024, 512, 512, 256]

# 经验回放缓存
memory:
  class: RandomMemory
  memory_size: -1  # 自动确定

# PPO 算法参数
agent:
  class: PPO
  rollouts: 250           # 每次更新的步数
  learning_epochs: 3      # 每次数据训练轮数
  mini_batches: 4         # minibatch 数量
  discount_factor: 0.99   # γ
  lambda: 0.95            # GAE λ
  learning_rate: 1.0e-04
  ratio_clip: 0.2         # PPO clip 参数
  value_clip: 0.2
  entropy_loss_scale: 0.0005  # 熵正则化系数
  
  # 状态预处理
  state_preprocessor: RunningStandardScaler
  
  # 日志配置
  experiment:
    checkpoint_interval: 10000

# 训练器
trainer:
  class: SequentialTrainer
  timesteps: 200000
```

### 2. skrl 多智能体配置 (IPPO/MAPPO)

文件：`config/agents/swarm_skrl_ippo_cfg.yaml`

```yaml
models:
  separate: True
```

### 3. rsl_rl 配置 (Python 类)

文件：`config/agents/swarm_rsl_rl_ppo_cfg.py`

```python
from isaaclab.utils import configclass
from isaaclab_rl.rsl_rl import RslRlOnPolicyRunnerCfg, RslRlPpoActorCriticCfg, RslRlPpoAlgorithmCfg

@configclass
class SwarmAccPPORunnerCfg(RslRlOnPolicyRunnerCfg):
    num_steps_per_env = 50      # 每轮每个环境步数
    max_iterations = 1000       # 最大训练轮数
    save_interval = 20          # 保存间隔
    
    policy = RslRlPpoActorCriticCfg(
        init_noise_std=1.0,
        actor_hidden_dims=[1024, 1024, 1024, 512, 512, 256],
        critic_hidden_dims=[1024, 1024, 1024, 512, 512, 256],
        activation="elu",
    )
    
    algorithm = RslRlPpoAlgorithmCfg(
        value_loss_coef=1.0,
        use_clipped_value_loss=True,
        clip_param=0.2,
        entropy_coef=0.0005,
        num_learning_epochs=5,
        num_mini_batches=4,
        learning_rate=2.0e-4,
        gamma=0.99,
        lam=0.95,
    )
```

## 五、训练脚本中的配置加载

### 1. skrl 训练脚本

```python
from isaaclab_tasks.utils.hydra import hydra_task_config
from skrl.utils.runner.torch import Runner

@hydra_task_config(args_cli.task, "skrl_ppo_cfg_entry_point")
def main(env_cfg: DirectRLEnvCfg, agent_cfg: dict):
    # 覆盖配置
    env_cfg.scene.num_envs = args_cli.num_envs
    agent_cfg["seed"] = args_cli.seed
    
    # 创建环境
    env = gym.make(args_cli.task, cfg=env_cfg)
    env = SkrlVecEnvWrapper(env, ml_framework="torch")
    
    # 使用 skrl 的 Runner
    runner = Runner(env, agent_cfg)
    runner.run()
```

### 2. rsl_rl 训练脚本

```python
from isaaclab_tasks.utils.hydra import hydra_task_config
from rsl_rl.runners import OnPolicyRunner

@hydra_task_config(args_cli.task, "rsl_rl_cfg_entry_point")
def main(env_cfg: DirectRLEnvCfg, agent_cfg: RslRlOnPolicyRunnerCfg):
    # 覆盖配置
    env_cfg.scene.num_envs = args_cli.num_envs
    
    # 创建环境
    env = gym.make(args_cli.task, cfg=env_cfg)
    env = RslRlVecEnvWrapper(env, clip_actions=agent_cfg.clip_actions)
    
    # 使用 rsl_rl 的 OnPolicyRunner
    runner = OnPolicyRunner(env, agent_cfg.to_dict(), log_dir=log_dir)
    runner.learn(num_learning_iterations=agent_cfg.max_iterations)
```

### 3. sb3 训练脚本

```python
from stable_baselines3 import PPO

@hydra_task_config(args_cli.task, "sb3_cfg_entry_point")
def main(env_cfg: DirectRLEnvCfg, agent_cfg: dict):
    # 创建环境
    env = gym.make(args_cli.task, cfg=env_cfg)
    env = Sb3VecEnvWrapper(env)
    
    # 直接使用 SB3 的 PPO
    model = PPO("MlpPolicy", env, **agent_cfg)
    model.learn(total_timesteps=n_timesteps)
```

## 七、命令行覆盖配置 (Hydra)

使用 Hydra 语法可以覆盖任何配置参数：

```bash
# 覆盖学习率
python reinforcement_learning/skrl/train.py \
    --task FAST-Swarm-Acc \
    agent.learning_rate=5e-5

# 覆盖网络结构
python reinforcement_learning/skrl/train.py \
    --task FAST-Swarm-Acc \
    'models.policy.network.layers=[2048, 2048, 1024, 512]'

# 覆盖训练步数
python reinforcement_learning/skrl/train.py \
    --task FAST-Swarm-Acc \
    trainer.timesteps=500000
```

## 八、算法来源说明

**重要：本项目没有自己实现 RL 算法，全部调用开源库**

| 库 | GitHub 仓库 | 开发者 |
|---|------------|--------|
| skrl | https://github.com/Toni-SM/skrl | Toni-SM (独立开发者) |
| rsl_rl | https://github.com/leggedrobotics/rsl_rl | ETH Zurich leggedrobotics |
| stable-baselines3 | https://github.com/DLR-RM/stable-baselines3 | 德国宇航中心 (DLR) |

### skrl 支持的算法

**单智能体：**
- A2C, PPO, TRPO, RPO
- DQN, DDQN
- DDPG, TD3, SAC
- CEM, Q-Learning, SARSA
- AMP (Adversarial Motion Priors)

**多智能体：**
- IPPO (Independent PPO)
- MAPPO (Multi-Agent PPO)

### rsl_rl 支持的算法

- PPO (仅支持 PPO，但优化得很好)
- Distillation (策略蒸馏)

### sb3 支持的算法

- A2C, PPO
- DQN, QR-DQN
- DDPG, TD3, SAC
- HER (Hindsight Experience Replay)

## 九、项目做了什么？

项目**只做了配置和调用**，没有自己实现算法：

1. **配置参数**：在 `config/agents/` 下写 YAML/Python 配置
2. **环境包装**：用以下 Wrapper 把 IsaacLab 环境转成对应库需要的格式：
   - `SkrlVecEnvWrapper` - 包装为 skrl 格式
   - `RslRlVecEnvWrapper` - 包装为 rsl_rl 格式
   - `Sb3VecEnvWrapper` - 包装为 sb3 格式
3. **启动训练**：调用各库的 Runner/Trainer

## 十、多智能体算法说明

### IPPO (Independent PPO)

每个智能体独立训练，把自己的队友当作环境的一部分。

```yaml
agent:
  class: IPPO
  param_sharing: True    # 所有智能体共享同一套网络参数
```

**特点：**
- 实现简单，每个智能体独立优化
- 非平稳环境问题（队友策略在变化）
- 适合协作任务

### MAPPO (Multi-Agent PPO)

 centralized critic，每个智能体共享 global state 信息。

```yaml
agent:
  class: MAPPO
```

**特点：**
- Critic 可以看到全局信息
- Actor 只能看到局部观测
- 适合需要全局协调的任务
