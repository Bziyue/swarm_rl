## 🎯 设计特点分析

### 1. 非对称卷积核设计

```
针对32×256长条形深度图的优化:

标准卷积 (k=3, s=2):
  32×256 → 15×127 → 7×63 → 3×31
  高度压缩太快，丢失垂直信息

本模型设计 (非对称stride):
  Conv1: s=(2,4)  ◄── 高度/2, 宽度/4 (快速压缩宽度)
  Conv2: s=2      ◄── 均匀压缩
  Conv3: s=(1,2)  ◄── 只压宽度，保留高度细节
  
最终: 32×256 → 14×63 → 6×31 → 4×15
      高度保留4层，适合检测障碍物高度信息
```

## ✅ 模型优势

1. **超轻量级**: 仅4.35M参数，适合Jetson Orin/Nano实时推理
2. **专用优化**: 针对32×256长条形深度图的非对称卷积设计
3. **Actor-Critic**: 标准PPO架构，训练稳定
4. **LayerNorm**: 比BatchNorm更适合RL的小batch训练
5. **特征复用**: CNN编码器在Policy和Value间共享，减少计算
